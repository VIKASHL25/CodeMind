# CodeMind - Project Documentation

## 1. Project Overview
**CodeMind** is an advanced, AI-driven platform designed to assist developers and data analysts by providing intelligent code analysis and data visualization capabilities. It utilizes a modern microservices architecture on the backend and a highly responsive single-page application (SPA) on the frontend. The system employs large language models (LLMs) and agentic workflows (via LangGraph) to reason about code and data, stream insights in real-time, and dynamically generate charts.

## 2. System Architecture

CodeMind is divided into two primary parts:
1. **Frontend:** A modern React application built with Vite.
2. **Backend:** A collection of Python FastAPI microservices, including an API Gateway, an Authentication Service, and an AI Orchestrator Service.

### High-Level Flow
1. The user interacts with the React frontend (e.g., submitting code or uploading a CSV).
2. The frontend sends HTTP requests or establishes a WebSocket connection with the **API Gateway**.
3. The Gateway routes authentication requests to the **Auth Service** and analysis requests to the **Orchestrator Service**.
4. The Orchestrator Service leverages a LangGraph-based agentic workflow to process the request and streams the output back to the frontend via WebSockets.

## 3. Backend Microservices

The backend consists of three distinct microservices, all built using **FastAPI** for high performance and asynchronous processing.

### 3.1 Gateway Service (`backend/gateway`)
- **Role:** Acts as the single entry point for the frontend application.
- **Responsibilities:**
  - Handles Cross-Origin Resource Sharing (CORS).
  - Validates JWT tokens using the Auth Service.
  - Proxies requests to the downstream services (`auth_service` and `orchestrator_service`).
- **Key Endpoints:**
  - `POST /auth/signup` and `POST /auth/login`
  - `POST /analyze/code` and `POST /analyze/data` (Protected routes)

### 3.2 Authentication Service (`backend/auth_service`)
- **Role:** Manages user identity and security.
- **Technologies:** MongoDB (Motor Asyncio), `passlib` for password hashing, `jose` for JWT tokens.
- **Responsibilities:**
  - User registration (Signup).
  - User authentication (Login).
  - JWT token generation and verification.
- **Key Endpoints:**
  - `POST /signup`
  - `POST /login`
  - `GET /verify`

### 3.3 Orchestrator Service (`backend/orchestrator_service`)
- **Role:** The core AI engine that processes code and data.
- **Technologies:** LangChain, LangGraph, WebSockets.
- **Responsibilities:**
  - Maintains the `AgentState` (user question, mode, code/data input, LLM reasoning, agent streams, chart configs).
  - Runs the LangGraph workflow (`codemind_graph`) to route requests to specific AI agents.
  - Streams real-time updates (routing decisions, agent outputs, chart configurations) to the frontend via WebSockets.
- **Key Endpoints:**
  - `POST /analyse/code` & `POST /analyse/data` (REST fallbacks).
  - `WS /ws/analyze` (Primary WebSocket endpoint for real-time streaming).

## 4. Frontend Application

The frontend is located in the `frontend/` directory and is built using **React** and **Vite**.

### 4.1 Key Pages
- **`HomePage.jsx`**: The landing page of the application.
- **`LoginPage.jsx`**: Handles user authentication and session creation.
- **`CodeModePage.jsx`**: The interface where developers can write or paste code, ask questions, and receive AI-driven code reviews, optimizations, or bug fixes.
- **`DataModePage.jsx`**: The interface where users can upload CSV datasets, query the data in natural language, and receive data analysis and dynamic visualizations.

### 4.2 Key Components
- **`CodeEditor.jsx`**: Provides a rich text editing experience with syntax highlighting for various programming languages.
- **`DataUploader.jsx`**: Handles drag-and-drop CSV file uploads.
- **`AgentPanel.jsx`**: Displays the real-time thought process and output streams from the various AI agents executing in the backend.
- **`ChartRenderer.jsx`**: Dynamically renders charts (e.g., Bar, Line, Scatter) based on configurations generated by the backend AI agents.

## 5. Core Features

### 🛠️ Code Mode
Users can input source code (e.g., Python, JavaScript) and ask specific questions. The Orchestrator Service spins up specialized agents to analyze the code, identify bugs, suggest performance improvements, or explain complex logic. The reasoning is streamed back to the `AgentPanel` in real-time.

### 📊 Data Mode
Users can upload tabular data (`.csv`) and ask questions like *"What is the sales trend over the last year?"*. The AI agents generate Pandas code to process the data, formulate chart configurations, and stream these configs to the `ChartRenderer`, which plots the data dynamically on the frontend.

### ⚡ Real-Time Streaming
Instead of waiting for a long-running LLM generation to complete, CodeMind uses WebSockets to stream intermediate steps (e.g., "Routing to Code Agent...", "Agent completed task"). This drastically improves the user experience by providing immediate feedback.

## 6. Setup & Execution Summary
1. **Frontend:** Run `npm install` followed by `npm run dev` in the `frontend` directory.
2. **Backend:** Ensure a MongoDB instance is running. Start the individual microservices using Uvicorn (e.g., `uvicorn main:app --port 8001`, `8002`, and the Gateway). Ensure `.env` files are populated with necessary API keys (OpenAI, MongoDB URI).
